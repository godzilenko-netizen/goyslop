# Универсальная подготовка иконок для Godot

`icon_pipeline.gd` решает типичную проблему AI-генераторов: расширение файла может быть `.png`, хотя внутри лежит WebP, JPEG либо изображение с посторонними байтами перед настоящим заголовком.

Инструмент не доверяет расширению входного файла. Он ищет сигнатуры PNG, WebP и JPEG в самих байтах, декодирует найденное изображение и сохраняет стандартный RGBA PNG, который нормально импортируется Godot.

## Одна иконка

```powershell
& "C:\path\to\Godot.exe" --headless --path . `
  --script res://tools/icon_pipeline.gd -- `
  --input "C:\Downloads\fireball.png" `
  --output "res://textures/skills/fireball.png" `
  --size 128 --mode cover --filter nearest
```

Расширение входного файла может быть неправильным. Расширение результата всегда должно быть `.png`.

## Пакетная обработка

Скопируйте `icon_manifest.example.json`, укажите входные и выходные пути и запустите:

```powershell
& "C:\path\to\Godot.exe" --headless --path . `
  --script res://tools/icon_pipeline.gd -- `
  --manifest res://tools/icon_manifest.json
```

## Параметры

- `--size 128` — итоговая ширина и высота.
- `--padding 4` — безопасное поле внутри квадрата в пикселях.
- `--mode cover` — заполнить квадрат с центральной обрезкой.
- `--mode contain` — вместить изображение полностью и добавить поля.
- `--mode stretch` — растянуть изображение точно в квадрат.
- `--filter nearest` — чёткий пиксель-арт.
- `--filter lanczos` — качественное уменьшение обычной иллюстрации.
- `--crop x,y,w,h` — предварительная ручная обрезка.
- `--trim-alpha` — убрать полностью прозрачные края.
- `--alpha-threshold 8` — порог прозрачности для автоматической обрезки.
- `--background #00000000` — цвет добавляемых полей в формате RGBA.

## Самопроверка восстановления формата

Команда создаёт временный PNG с мусорными байтами в начале и неправильным расширением `.webp`, восстанавливает его и проверяет результат:

```powershell
& "C:\path\to\Godot.exe" --headless --path . `
  --script res://tools/icon_pipeline.gd -- --self-test
```

Успешный результат заканчивается строкой `ICON_PIPELINE_SELF_TEST_OK`.

## Рекомендуемый рабочий процесс

1. Просить генератор не рисовать рамку интерфейса внутри самой картинки.
2. Оставлять фон иконки, если он является частью художественного оформления.
3. Сохранять исходник в максимальном доступном качестве.
4. Прогонять исходник через `icon_pipeline.gd` в 128×128.
5. Один раз открыть проект в редакторе или запустить headless-импорт, чтобы Godot создал локальный `.ctex`.
6. Не добавлять содержимое `.godot/` в Git — кэш импорта создаётся на каждом компьютере автоматически.

Старые скрипты с абсолютными путями больше не нужны: этот инструмент работает с любым расположением проекта и исходных изображений.
